# Funk Lab

A browser-based funk and G-funk music maker. Build beats on a 2-bar, 16-step sequencer with drums, percussion, bass, Rhodes-style keys, wah guitar and a gliding whine lead. It's plain HTML, CSS and the Web Audio API, with no dependencies and no build step.

## Features
- **8 presets:** Cruise (G-funk), Funk shuffle, Boom bap, Disco funk, Boogie talk-box, Slow jam (808), Latin funk, Funky break
- **Drums and percussion:** kick, snare, clap, hi-hat, open hat, shaker, conga, cowbell
- **Bass:** funk pluck or 808 sub
- **Keys:** Rhodes-style chord stabs that follow a chord progression
- **Guitar:** muted chicken-scratch, wah chords and pentatonic lick notes
- **Lead:** monophonic synth with portamento and vibrato
- **Controls:** tempo, swing, any minor key, 5 chord progressions, echo, vinyl crackle, per-group volume and mute
- **Tools:** Add fill, Remix, Randomize, Copy bar

## Run it
Open `index.html` in any modern browser. Press **Space** to play and stop.

## Host it free with GitHub Pages
1. Push this folder to a GitHub repo.
2. Go to **Settings > Pages**.
3. Under "Build and deployment", choose **Deploy from a branch**, then `main` and `/ (root)`.
4. Your site goes live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
